# 猫咪 IP 伴游交互

页面右下角固定一只猫咪 IP（`#mascot`），是贯穿全站的陪伴角色。

## 实现
- 结构：`.mascot` 内 `#cat` 符号 + 白色圆形底 + `.bubble` 气泡
- 动画：`breathe` 关键帧（3.6s 呼吸缩放）
- 交互：点击触发 `showBubble()`，从 `msgs` 数组随机取「喵语」显示 2.6s；页面加载 1.2s 后自动显示一次欢迎气泡

## 喵语文案
`喵~ 欢迎来玩！`、`今天也要元气满满哦`、`要陪我一起追番吗？`、`(=^･ω･^=)`、`来摸一下爪爪？`、`猫生理想：躺平晒太阳`

## 注意
- 猫咪 IP 位置与「回到顶部 / BGM」悬浮按钮（`.floating-btns`）垂直排布，避免重叠。
- 若后续要改文案，直接改 `index.html` 底部 JS 中 `msgs` 数组。
