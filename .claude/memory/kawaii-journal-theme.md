# 日系少女手账风设计

康家怡网站的视觉方向，由用户从 4 个候选风格（日系少女手账 / Y2K 像素游戏养成 / 清新插画留白 / 新粗野贴纸拼贴）中选定。

**核心定位**：软萌治愈系，贴合人物「18 岁、喜欢猫和追剧、活泼可爱灵动」的设定。

## 配色（CSS 变量）
- 主色樱花粉 `--sakura #FFAFC5` / 深 `--sakura-deep #FF8FAB`
- 薄荷绿 `--mint #A9E5C3` / 香芋紫 `--taro #C9B6E4` / 暖黄 `--lemon #FFD98E` / 天蓝 `--sky #A8D8EA`
- 背景奶油白 `--cream #FFF9F2`（带圆点纸纹），正文暖棕 `--ink #6B4F4A`

## 字体
- 标题：`ZCOOL KuaiLe`（站酷快乐体，圆润手写感，CDN）
- 正文：`M PLUS Rounded 1c` + 系统圆体族

## 手账元素
- 圆角卡片（16–28px）、软阴影、washi 胶带（`.tape`）、兴趣卡片墙（`.hobby-card`）、拍立得相框、虚线描边、手写波浪下划线（`h2::after` 内联 SVG）

## 与另外两个项目的差异
前两个项目面向成熟人群（水墨庄重 / 桃花温暖），本项目为年轻化突破：高明度低饱和奶油色、圆体手写字体、动漫贴纸语言。配色与气质不可向沉稳方向回退。
