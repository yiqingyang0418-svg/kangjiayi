# 5 板块信息架构

康家怡网站采用 5 个单页板块，自由滚动叙事（与易德忠的翻页、吴雪飞的长卷均有区别）。

## 板块顺序与 id
1. `#hero` 封面 —— 手账封面：头像 + 名字 + 自我介绍 + 漂浮贴纸
2. `#about` 关于我 —— 档案卡（永远 18 岁 / 星座 / 城市 / 身份 / 梦想，信息行带彩色图标徽章）
3. `#world` 我的小世界 —— 兴趣卡片墙（6 爱好各 4 照片位）
4. `#gallery` 相册 —— 拍立得照片墙（32 张占位）
5. `#contact` 老易寄语 —— 「给我留言」小版块（老易的七夕祝福）

## 导航
顶部导航 `.nav-links` 对应上述 4 个锚点（不含 hero，hero 由 logo 返回）。增删板块时需同步：`<section>`、`.nav-links` 的 `<a>`、以及本文件与 `CLAUDE.md` 的「页面结构」表。
