# 内联 SVG 符号系统

为保证单文件自包含 + 离线可用，所有装饰性图形都用内联 SVG 实现，不用外部图片。

## 定义位置
`index.html` 顶部一个隐藏的 `<svg width="0" height="0">` 内，`<defs>` 中定义 6 个 `<symbol>`，通过 `<use href="#id">` 复用。

## 符号清单
| id | 内容 |
|----|------|
| `#cat` | 猫咪（圆脸 + 三角耳 + 闭眼笑 + 胡须 + 铃铛），全局猫咪 IP |
| `#girl` | 女孩头像占位（猫耳发箍 + 圆脸 + 腮红），Hero 与关于我 |
| `#paw` | 爪印（导航 logo / 页脚 / 贴纸） |
| `#heart` | 爱心 |
| `#sparkle` | 四角星闪光 |
| `#flower` | 花朵（四瓣 + 黄花芯） |
| `#cake` | 生日蛋糕（关于我·年龄徽章） |
| `#pin` | 地图定位针（关于我·城市徽章） |
| `#grad` | 学士帽（关于我·身份徽章） |

## 注意
- 符号内部使用硬编码色值（如 `#FFAFC5`），因 SVG 表现属性不支持 `var()`；改配色时需同步修改符号内的 hex 值。
- `images/icon.svg` 是独立的 PWA 图标（猫脸方形圆角），与 `#cat` 符号同造型但独立文件，改动时需同步。
- 新增装饰图形优先加新 `<symbol>`，而非引入图片。
